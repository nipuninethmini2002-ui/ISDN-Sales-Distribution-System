ISDN Sales & Distribution System

Project Overview
This is a web-based sales and distribution management system developed to streamline the process of product ordering, delivery tracking, and role-based management.

User Roles

The system supports 4 distinct user roles:
1. Admin / HO Admin: For overall system management.
2. RDC Staff: To manage regional distribution.
3. Customer: For product viewing and order placement.
4. Delivery Personnel: For managing logistics and delivery status.

Main Features
1. Authentication: Secure login with role-based access control (RBAC).
2. Orders: Real-time product viewing and order placement.
3. Communication: Automatic order notifications via email integration.
4. Billing: Instant invoice generation and viewing.
5. Dashboards: Customized dashboards for each user role.

Technologies Used
1. Backend: PHP
2. Database: MySQL
3. Frontend: HTML5, CSS3, JavaScript
4. Libraries: PHPMailer (for email functionality)

Setup Instructions
1. Clone/Download: Download the repository to your local machine.
2. Database: Import the database.sql file into your MySQL database via phpMyAdmin.
3. Configuration: Update your database credentials (host, username, password) in the db.php file.
4. Execution: Move the project folder to htdocs and run it using a local server like XAMPP or WAMP.
