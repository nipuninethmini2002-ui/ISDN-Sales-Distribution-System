ISDN Sales & Distribution System
Project Overview
This is a web-based sales and distribution management system developed to streamline the process of product ordering, delivery tracking, and role-based management.

User Roles
The system supports 5 distinct user roles:

Admin / HO Admin: For overall system management.

RDC Staff: To manage regional distribution.

Customer: For product viewing and order placement.

Delivery Personnel: For managing logistics and delivery status.

Main Features
Authentication: Secure login with role-based access control (RBAC).

Orders: Real-time product viewing and order placement.

Communication: Automatic order notifications via email integration.

Billing: Instant invoice generation and viewing.

Dashboards: Customized dashboards for each user role.

Technologies Used
Backend: PHP

Database: MySQL

Frontend: HTML5, CSS3, JavaScript

Libraries: PHPMailer (for email functionality)

Setup Instructions
Clone/Download: Download the repository to your local machine.

Database: Import the database.sql file into your MySQL database via phpMyAdmin.

Configuration: Update your database credentials (host, username, password) in the db.php file.

Execution: Move the project folder to htdocs and run it using a local server like XAMPP or WAMP.
